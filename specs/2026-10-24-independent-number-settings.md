# 导航与正文独立序号设置

## 入口与配置

- 正文原序号开关仅控制正文与右侧本文目录；紧邻它增加「序号设置」按钮。
- 左侧顶层「所有文档」旁增加「序号：开/关」按钮，只控制导航；点击不会跳转或折叠目录。
- 设置弹窗提供两个独立区域。导航起点可选第 1–12 层，正文起点可选 H1–H6；各自选择最多显示多少层、层级/连续模式、阿拉伯/中文/罗马/字母格式、无标点/尾随点/括号/顿号，以及淡色/加粗/徽标样式。
- 两侧默认开启；正文默认 H2 起三层，导航默认从顶层分组下一层起最多十二层。只显示而不自动增加不存在的标题；跳级时不显示零前缀。
- 设置保存至 localStorage 的 `md2web.workspace.numbering.v1`，本站各文档共享当前浏览器偏好；不写服务器配置或用户 Markdown。旧的联动开关不再控制两侧，新设置尚未保存时均按开启处理。
- 保存才应用修改；取消/Esc 不应用；恢复默认先更新表单，保存后生效。弹窗支持桌面双栏、窄屏单栏滚动，以及每侧实时编号预览。

## 实现约定

- `web/workspace.js` 共用校验与编号函数计算正文标签，正文用 `data-workspace-number` 和伪元素显示，避免修改标题文字/ID/链接。
- `window.SiteNumbering` 给右侧目录提供相同标签，避免 CSS 计数器与 JavaScript 双算导致不一致；目录范围扩展以覆盖选定的 H1–H6 编号范围。
- 左侧使用 `hide-tree-numbers`，正文保留 `hide-heading-numbers`；开关、层级、模式、格式和显示样式分别保存。
- 过滤后的导航条目保持连续编号；折叠不改变编号。复制正文和导出独立 HTML 将当前显示编号转换为文本，避免复制后回到固定的 H2–H4 编号。
