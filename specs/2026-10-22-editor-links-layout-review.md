### R1 · P2：中文加粗兼容处理改写非正文内容

位置：`web/math-init.js` 的 `prepareStrong()`（审查时第 19–27 行）。

复现输入与实测结果：

```markdown
![**答案： **](image.png)
<span title="> **答案： **">text</span>
```

- 第一例原本生成图片替代文字 `**答案： **`；兼容处理后替代文字变成 `<strong>答案：</strong>`。图片加载失败或辅助技术读出时会出现 HTML 标记文字。
- 第二例合法属性值含 `>`，当前 `<[^>\n]*>` 在引号内部提前结束，后面的 `**答案： **` 被转换，直接改变 title 属性值。

两例均用当前 `MathRender.prepare()` + 本地 marked 实际复现。影响编辑器与阅读页的渲染结果，不修改原 Markdown。本次没有证实可执行脚本注入。

建议：基于 Markdown token 类型仅处理正文文本，显式排除图片替代文字、链接地址、HTML 属性；如暂留词法扫描，HTML 标签必须支持成对引号，增加图片/引用式图片测试。

### R2 · P2：站内文件引用遗漏合法目录

位置：`server/internal_files.py` 的 `EXCLUDED` 与 `search()` 目录过滤。

在临时 docs 下创建三个实际文件：

```text
pdf/normal/manual.pdf
pdf/images/manual.pdf
md/demo/images/chart.png
```

调用 `search(root, '')` 实际只返回 `pdf/normal/manual.pdf`。当前按任意层级目录名过滤 `images`、`uploads`，将普通资料子目录与反馈运行目录混为一谈。接口声明支持 PNG/JPEG 等图片，但编辑器上传到文档同级 images 的图片不能被引用搜索找到。

另一个已知限制：搜索不跟随目录链接，站点已配置的一级软链接仓库内附件也不会出现；该限制已有实现文档说明，本报告不把它算作第二个独立 BUG。

建议：对反馈运行目录按完整相对路径排除；普通库下同名目录照常扫描。若扩展软链接支持，复用 `folder_sources.walk_paths` 的一级挂载规则，继续拒绝嵌套链接及私有文件。

### R3 · P2：访问记录失败后的重试被提前返回阻断

位置：`web/workspace.js`，`addUpdatedMeta()` 中 `data-route` 提前返回与 `lastVisitRoute` 状态更新。

复现方法：模拟第一次 `POST __md/visit` 网络失败，等待 catch 将 `lastVisitRoute` 清空，再对同页调用增强逻辑。实测：

```json
{"lastVisitRoute":"","renderedRoute":"md/demo/article","attemptsAfterTwoEnhancements":1}
```

原因：元数据框仍保留当前 data-route，第二次调用在检查访问记录状态之前返回。因此清空 lastVisitRoute 并不能促成重试，未登录或登录访客均可能漏记该次阅读，直到重新加载/重新进入文档。这不是匿名记录查询权限的问题。

建议：拆分元数据渲染与访问采集状态机，加入有上限的延迟重试；同时使用每次打开生成的事件 ID 做服务端幂等去重，避免“服务端已写入、响应丢失”时重复计数。成功后 DOM 重绘不应重复计数，切换文章应取消旧重试。

## 需后续压测的风险（不作为已复现故障）

- `__admin/user-records` 在共享数据库锁内扫描、聚合全部历史审计并生成 JSON，前端只做显示分页。数据持续增长后可能延迟其他认证请求。建议时间范围/服务端分页、缩短锁持有时间，并用实际日志量压测。
- 每次文件搜索都遍历 docs，MD 链接搜索每次读取完整索引；50 条返回上限并不减少扫描成本。可按索引 mtime 建短期缓存，验证重建后失效。
