# 工程师离线文档工作台

## 目标与约束

保留 Docsify 阅读、全文检索、标题跳转、搜索历史、命中阅读模式与 F3、侧栏调宽、本文目录、图片缩放、Prism 高亮、file:// 与 HTTP 预览、命令行接口及源文件就地维护。所有新增运行时资源必须随 docs/ 分发；不增加 Python 或 Node 运行依赖。

多文件夹指 docs/md/ 内任意深度的目录，沿用当前单源架构，不重新引入已被取代的多外部源复制方案。

## 方案选择

1. **采用：渐进增强 Docsify 工作台。** 保留现有实现，补足导航信息、检索范围与工程操作，兼容离线产物。
2. 只改 CSS：风险低，但不能解决目录身份丢失和代码漏检。
3. 重建 SPA：可定制程度高，但引入迁移和构建成本，难以保证原有功能完整保留。

## 页面与导航

- 左侧完整目录树：保留单文件目录名称，支持折叠、递归文档数、文件名/路径过滤、全部展开收起、定位当前文件。按完整路径记忆展开状态。
- 中央阅读区：路径面包屑、复制源文件相对路径、复制代码、宽屏阅读；表格和代码在本区横向滚动。
- 右侧沿用本文目录；较窄窗口让出阅读空间，手机保留可打开的侧栏。
- 首页显示文档/文件夹计数、按顶层目录划分的入口卡片、可展开完整索引和离线操作说明。

## 搜索

- 保留 Ctrl/Cmd+K 与 /；新增 Ctrl/Cmd+P 文件模式。
- 全文/文件模式可切换，范围为全部、当前文档或任意嵌套文件夹；路径边界必须精确，避免相似目录串组。
- 多词为 AND，支持引号短语和排除词；中文、英文、带标点符号的工程标识可检索。
- 标题、文件名、路径优先于正文，按文件展示完整相对路径与命中片段。显示真实总文档数与当前截断数量。
- Python 预构建和浏览器重读采用一致标题/围栏语义，代码进入正文但代码中的 # 不生成标题。
- 页面重读仅刷新已有路由或内嵌快照；新增/删除文档与 file:// 内容更新需重新构建并刷新页面，界面说明这一限制。
- 继续保持搜索历史、页内命中跳转与折叠；短语/排除过滤只把正向查询用于阅读高亮。

## 边界与验证

所有用户标题/路径插入 HTML 时转义；本地存储失败不影响查阅。复制在 file:// 下有后备方式。现有特殊文件名路由限制保留说明。

以原 49 项 Python 测试为基线，新增目录身份、首页、代码索引与生成资源测试；用 Node 标准库测试搜索算法与边界；真实浏览器检查 file:// 与 HTTP、目录筛选/跳转、键盘搜索、代码高亮、窄屏与宽屏。验证构建前后 docs/md/ 文件字节不变，依赖齐全时构建不访问网络。
