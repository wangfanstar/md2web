# MD 网页保留格式复制

MD 网页顶部公共工具栏新增「复制本页内容」，位于「下载本页」旁；文档、概览和文件夹视图均显示，复制当前页面正文。点击后在 Word、邮件或其他富文本编辑器粘贴，按需选择「保留源格式」。

- 同时写入 HTML 与纯文本剪贴板格式，保留标题、章节序号、加粗/斜体、文字颜色、表格边框、列表、代码与链接。
- 只复制文档正文，排除面包屑、导航、最后更新时间和操作按钮；包含折叠章节内的正文，不改动阅读页或源文件。
- 图片优先转为内嵌数据；公式从 MathML 转为 PNG，Mermaid/SVG 转为 PNG，Canvas 复制原始绘制结果。图形以图片形式粘贴，不是 Word 可编辑公式。无法内嵌的资源会明确提示，图片可能仍需要网络。
- HTTPS/本机优先使用异步 Clipboard API；普通 HTTP 或不支持该 API 时使用带 HTML/纯文本的 copy 事件兼容方式，恢复原来的选区与焦点。失败明确提示，不把纯文本复制冒充保留格式成功。
- 功能合并在既有 page-export.js 中，通过既有入口页加载；服务器上的旧仓库入口无需新增脚本标签。

验证：Python 3.6.8 全量 576 项（跳过 1 项），Node 128 项、语法检查、严格离线构建通过。真实 Edge 浏览器验证 HTML/纯文本剪贴板、富文本粘贴、表格和列表、公式与图表内嵌、原画布像素、折叠内容、选区恢复、失败反馈、普通 HTTP、file:// 和旧入口页。

本机未安装 Word，未声称完成 Word 原生客户端粘贴验收；接收软件及其粘贴选项会影响最终排版。
