# 提权管理员登录与用户记录

## 登录修复

管理员登录入口先识别本地恢复管理员；其他账号匹配当前 SVN 认证源，并根据数据库角色和 JSON 授权配置计算有效权限。已启用的管理员使用原 SVN 密码认证，沿用限速、审计、加密凭据保存与会话策略。普通用户、禁用用户和错误密码不能从管理员入口登录；不创建额外的本地密码。

## 用户记录 Tab

配置页新增“用户记录”，管理员可查看所有保留的登录 IP、账号、认证源、成功/失败结果、次数和最近时间。支持筛选和每页 100 条显示，不再沿用旧使用情况接口最多 200 条的限制。

排行榜包括成功登录次数、文章访问次数、阅读文章总数（去重路径），并提供文章访问次数/阅读人数排行。文章总数表示阅读覆盖范围，不代表作者贡献。零访问用户仍列出。

登录记录沿用历史审计数据；文章阅读从更新后开始，仅统计已登录用户打开或刷新文档。离线浏览、匿名浏览不记录，同页元数据刷新不重复记录。历史上没有采集的阅读行为不能补算。

`POST /__md/visit` 要求登录、同源与 CSRF，校验文档存在；`GET /__admin/user-records` 仅允许管理员读取。写入既有 SQLite 审计表，新增两个普通索引（schema v13），兼容 SQLite 3.7.17 与 Python 3.6.8。统计以服务器看到的 remote_addr 为准，不信任客户端伪造的代理头；使用反向代理时可能显示代理 IP。

前端按管理员身份隔离结果，退出时清理数据，忽略身份变化后的旧响应。只在打开 Tab 或点击刷新时请求，不持续轮询完整报表。

## 部署与验证

拉取代码后使用 Python 3.6.8 运行 `python3 setup_docsify.py --offline`，随后重启认证服务。构建读取服务器自己的 docs/md，勿用其他机器的首页清单覆盖服务器仓库。

回归覆盖提权/降权/禁用/密码失败、访问次数与去重文章数、超过 200 条 IP、匿名/普通用户权限、CSRF 和不存在的文章；浏览器验证新 Tab、筛选及排行选择。数据库索引在服务启动迁移时自动创建。
