## 已修复问题

| 级别 | 问题与影响 | 修复 |
| --- | --- | --- |
| P1 | 面包屑无条件写入 `innerHTML`，触发 MutationObserver 循环；鼠标按下和松开之间链接节点被替换，造成点击无效及持续重绘 | 仅在内容发生变化时更新节点；浏览器测试按住鼠标 150 ms 后释放，验证跳转及节点稳定性 |
| P1 | Docsify 截获独立 HTML 入口；仅停止冒泡无法可靠完成导航 | 在 window 捕获阶段处理本站相对 HTML 链接，使用浏览器实际解析后的绝对地址跳转；保留修饰键、新窗口、下载和目录折叠行为 |
| P2 | 捕获阶段直接跳转阻止编辑器收到原来的站内导航事件，可能重新弹出全站草稿提醒 | 发出明确的站内导航通知，与编辑器共用离开规则；刷新/关闭页面仍保留提醒 |
| P1 | 通过 JSON/配置方案禁用用户后，如果用户没有发请求便重新启用，原会话可能恢复 | 配置应用时立即撤销被禁用用户会话；重新启用必须重新登录 |
| P2 | 预设禁用策略针对尚未入库的用户时，首次登录可能在创建会话后产生内部错误 | 创建会话前再次核对有效策略，返回明确的禁用错误 |
| P2 | 预览服务 HEAD 请求未复用 GET 静态禁止清单 | 在共用 `send_head` 校验受保护路径；增加 HEAD 404 回归 |
| P2 | 每次带版本参数的静态请求都重新读取整个 JS/CSS 计算摘要 | 对文件路径、纳秒修改时间和长度的摘要做最多 512 项缓存，仍校验请求版本，错误版本不设置 immutable |

同一轮检查确认：仓库改名配置写失败会恢复目录和历史；权限接口有管理员与 CSRF 校验；同 IP 的不同设备不共享用户名提示；比较历史按路径和用户限制读取；比较区以文本节点显示内容。
