# 配置页多 Tab 实现与代码检查

日期：2026-10-21。对应方案：[多 Tab 布局方案](2026-10-20-config-tabs-layout-plan.md)。

## 实现

配置页分为仓库管理、账号与权限、备份与恢复、AI 设置、缓存与性能、配置方案六个 Tab。仓库表格只展示概要，单仓库编辑使用侧栏抽屉，支持名称、来源、分组与状态过滤。保留原仓库 ID、来源类型及已有接口。

普通表单共用待保存栏，跨 Tab 编辑保留，保存前可查看脱敏差异。同步凭据单独验证保存，并提示尚未保存的凭据；保存普通配置不会丢失输入中的凭据。JSON 编辑期间锁定普通配置与凭据字段，提供取消编辑。配置方案支持只读预览；版本冲突保留当前修改，可与服务器最新配置比较。

账号权限与回收站按需加载，首次进入不自动批量检查 SVN。支持键盘切换 Tab、旧锚点跳转、手机布局及登录失效后的敏感内容清理。运行时资源仍全部本地化。

## 检查中修复的问题

- 刷新仓库列表会覆盖未保存编辑：有普通修改或待保存凭据时保留编辑内容。
- 检查连接会隐式保存输入密码：检查与保存凭据分开。
- 配置保存与重建失败混淆：接口返回 rebuilt，页面明确提示已保存但待重建。
- 旧身份或旧加载请求晚到后覆盖页面：增加身份与加载代次检查。
- 保存期间继续输入可能丢失编辑：保存时锁定配置输入。
- 配置方案切换缺少版本检查：携带版本时服务器对过期请求返回 409。
- JSON 与普通表单同时编辑可能互相覆盖：锁定字段并阻止立即生效的操作。
- 浮动反馈入口遮挡移动端保存按钮：待保存栏出现时上移反馈入口。

## 验证与范围

使用 Python 3.6.8 完成全量 unittest，Node 完成 124 项测试及前端语法检查，严格离线构建通过。真实 Edge 浏览器连接隔离的认证服务，验证六个 Tab、仓库抽屉、跨 Tab 保存、待保存凭据保留、409 冲突、方案预览、非法 JSON 保留、用户按需加载、移动端与退出后敏感内容清理。

此次检查集中于配置页及相关接口。浏览器使用测试 SVN 适配器，未对生产服务器或真实 SVN 仓库执行写操作。缓存参数沿用服务端现有机制，修改后需重启服务；轮询仍采用现有周期，页面已注明。未修改 docs/md 源文档或公开提交私有配置与凭据。
