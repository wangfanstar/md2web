# 800GBASE-R 三维通道逐项复核

核对版本 `1bfe755`，对象为 [800GBASE-R 实验](../docs/html/ref/visual-pcs.html#lab-800g) 的 32:8 PMA 拓扑。条款依据 [IEEE Std 802.3df-2024 本地 PDF](../docs/pdf/8023df-2024.pdf)。实体以[场景的 modules 和 addModules()](../docs/html/ref/visual-pcs-assets/pcs-800g-view.js)为准，数据计算以[800G 模型](../docs/html/ref/visual-pcs-assets/pcs-800g-model.js)为准。

## 复核结论

正常通路有 **17 个阶段、37 个立体方块**（15 个共享方块，两个 Flow 各 11 个方块）。旧清单所列 TX Flow 1 和 RX Flow 0 的七个方块已补齐。TX/RX 速率匹配、FEC 后交织、AM 移除、CDR、Gray 解映射和条件预编码也已有实体。

**仍缺 PCS 的 Scrambled Idle 测试发生器。** 对于实例化的电气接口，信号驱动器没有单独绘出，PMA 的 SIGNAL_OK 指示逻辑也没有完整展示。PMA 本地环回、远端环回和测试图样属于可选支路，当前均未绘出。正常 RX 路径中，按 AM 识别并重排 lane、去交织重建码字仍适合分开呈现。

## 补图优先级

1. 增加 PCS Scrambled Idle 入口，验证实际进入 lane 的数据随模式变化。
2. 在 RX 追踪一条 lane：从物理输入解复用、捕获 AM、识别 UM、重排，再去交织；分别显示 PMA SIGNAL_OK 与 PCS align_status。
3. 选定物理接口后，补驱动器及适用的逆预编码；选配 PMA 环回和测试发生／检测支路。

本次按 32:8 PMA 核对。8:32、8:8 属替代拓扑，具体 PMD、管理寄存器及整套 PHY 合规验证不在本表范围。依据为草案以外的正式 802.3df-2024 标准与当前源码，未作浏览器逐帧验收。
