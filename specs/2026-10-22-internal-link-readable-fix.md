# 站内链接中文显示与分步选择修复

## 问题与修复

- 用户反馈链接中的 `%E4%BD%…` 是 URL 百分号编码。站内文档、章节与附件链接现在保留可读中文；空格、井号、百分号、引号等 ASCII 特殊字符继续编码，插入 HTML 时仍转义属性和链接文字。
- 回归测试复现：文档按钮重复触发时，旧处理器依据已经改变的 `selectedDoc` 状态，把第二次事件解释为插入操作，绕过章节选择。
- 现在按结果的 `document` / `heading` 类型分派，并拒绝已过期的列表事件、禁用已点击按钮。文档结果只打开章节列表；章节结果必须属于当前选中的文档才能插入。整篇文档保留独立的「插入整篇文档」按钮。

## 使用方式

编辑器点击「站内文档链接」→ 搜索并选择文档 → 搜索并选择章节，或点击「插入整篇文档」。支持返回文档列表，保留原搜索条件。

本次影响新插入的链接；已有百分号编码链接仍有效，不自动改写用户文档。浏览器地址栏、DOM URL 属性可能自动编码中文，不影响 Markdown 源码中的中文可读性。

- Python 单元测试覆盖中文可读性、特殊字符编码、文档/章节两阶段查询。
- 浏览器测试覆盖重复激活文档按钮不插入、中文文件名、重复中文标题准确跳转到第二个标题、新标签页、整篇文档插入与返回搜索。
- 验收通过：Python 3.6.8 全量 585 项（跳过 1 项）、Node 139 项、全部 web JavaScript 语法检查、两组浏览器回归（文档链接/布局及站内附件/登录）、离线构建。
- 前端源码与构建产物同步更新。Linux 拉取后重启认证编辑服务并重新打开页面；若部署时需要重建索引，应在服务器实际文档目录上运行离线构建，保留服务器现有仓库。
