# 1.6TBASE-R 三维实验逐项复核

本次基线为 `2137d62`。核对 [P802.3dj/D2.0 草案](../docs/pdf/8023dj_D2p0.pdf) 第 175 条 PCS 与第 176 条 16:8 SM-PMA，对应[实验页面](../docs/html/ref/visual-pcs.html#lab-1600g)和[渲染及数据源码](../docs/html/ref/visual-pcs-assets/pcs-1600g-view.js)。下表中“已绘”指存在可辨认的三维实体；数据处理、弹窗和测试模式另行说明。核对方法为静态源码与草案逐项对照。

## 本次结论

上次指出的 TX/RX 速率匹配、FEC 前分配与后交织、TX AM 锁定、40 位对齐、RX 四元组锁定、AM 移除均已有实体。每条 PCS lane 的四元组包含 A/B/C/D，接收终点也已从解码数据合流取字节。当前直接可见的遗漏主要是**条件适用的 PAM4 预编码/逆预编码，以及按物理接口配置的 PMA 测试、环回等支路**。正常 PCS 主路径最明显的合并项是 RX 去交织与 RS 解码。另有几处已经画出方块，但方块的输出仍是教学示意。

|---|---|---|
| 176.4.2.1、176.4.3.5 | 上侧 TX PAM4 解码、RX PAM4 编码 | 上接物理 1.6TAUI-16 时适用。当前仅画下侧八路 PAM4，扩展该拓扑时需补上侧处理。 |
| 176.4.2.2 | TX 输入 AM 锁定 | 已绘。发侧状态固定为 16/16，未逐 PCSL 捕获。 |
| 176.4.2.3.3 | 40 位 deskew | 已绘。缺 TX 逐 lane 延迟补偿前后的时序；RX 的 152 ns 控件对应 PCS 接收容限。 |
| 176.4.2.5.2 | 符号四元组复用 | 已绘并实际按两条 PCSL 交替组成物理输入。相邻配对是示例选择。 |
| 176.4.2.6、176.4.3.1、176.7.1.1 | 下侧 PAM4 编码/解码、Gray 映射 | 两个实体均已绘，弹窗显示位对和电平。链路模型的传输单位仍为符号四元组。 |
| 176.7.1.2 | 预编码、逆预编码 | 缺少条件节点、逐 lane 启用状态及模 4 运算示例。应按草案对应接口的能力与使能条件展示。 |
| 176.4.3.2.2 | RX 边界锁定、1:2 解复用 | 分别已绘。decode() 支持符号偏移，查找已知发送样本以恢复边界；未实现图 176–11 锁定状态机。 |
| 176.4.3.2.3 | 解复用后逐 PCSL AM 锁定 | 已绘并随物理失锁改变 lane 数量。样本识别与 PCS 层共用，两个层次的独立状态迁移未展开。 |
| 176.4.2.4、176.4.3.3 | 人工延迟奇数/偶数 lane | 16:8 四元组路径额外延迟为零，无须补绘。 |
| 176.4.2.5.1、176.4.3.2.1、176.4.3.4 | 符号对复用及解复用、特定 PMA 重排 | 属其他配置，勿混入本路径。 |
| 176.4.4 | PMA 状态与信号逻辑 | 有状态面板，部分状态借用同一 RX 锁定计数。特别是 align_status_mux 应区分 TX 复用器与 RX 解复用器的数据来源。 |
| 176.7.2、176.7.3 | PMA 本地/远端环回 | 缺支路；二者均为可选能力。 |
| 176.7.4 | PMA 测试图样产生、检测 | 缺接口侧产生器和检测器。适用性取决于实际实例化接口及图样类型。PCS Scrambled Idle 按钮只覆盖第 175 条的教学入口。 |

**补图优先级**：先让 AM 构造、锁定、重排及状态提取使用同一份接收数据，并用附录 175A 向量检查位序；随后贯通 Scrambled Idle 到实际 lane 输出。扩展到指定 AUI/PMD 时，再按接口补齐预编码、PMA 测试支路及适用的上侧 PAM4。未进行浏览器逐帧验收或协议一致性测试。
