# 中文加粗标签显示修复

截图中的 `**答案： **块同步`（标记内尾随空格），以及 `**答案：**块同步`（中文标点后紧接正文），不符合解析器默认强调边界规则，因而将星号直接显示出来。

在阅读页与编辑器已共用的 Markdown 预处理流程中，对这两类含中文的纯文本加粗标签做兼容转换：仅渲染时生成 strong 标签，不修改源 Markdown、不插入不可见字符。一般标准加粗仍交由原解析器处理。

代码围栏、行内代码、缩进代码、转义星号、原始 HTML 属性、链接目标和公式不做此转换；继续使用已有 HTML 净化流程。复杂嵌套强调仍遵循原 Markdown 语法。

验证：Node 回归包含截图写法、无空格写法、两端空格和受保护内容；真实浏览器验证生成阅读页与编辑器预览均生成 strong 元素，同时确认多行公式仍正常渲染。
