# 中文加粗标签显示修复

截图中的 `**答案： **块同步`（标记内尾随空格），以及 `**答案：**块同步`（中文标点后紧接正文），不符合解析器默认强调边界规则，因而将星号直接显示出来。`**为什么倒序遍历 (543 - 4*k - j) ?**` 中的 `4*k` 是词内星号，按 Markdown 规则应保持字面量，但阅读页使用的 marked 1.x 会把它误当成强调分隔符，导致外层加粗失效并漏出星号。

在阅读页与编辑器已共用的 Markdown 预处理流程中，对上述含中文的纯文本加粗标签做兼容转换；词内星号（两侧均为文字/数字，如 `4*k`、`参数*变量`）先按字面量转义，再交给解析器，保证阅读页与编辑器预览一致。仅渲染时处理，不修改源 Markdown、不插入不可见字符。

代码围栏、行内代码、缩进代码、转义星号、原始 HTML 属性、链接目标和公式不做此转换；继续使用已有 HTML 净化流程。复杂嵌套强调仍遵循原 Markdown 语法。

验证：Node 回归包含截图写法、无空格写法、两端空格、词内星号和受保护内容；真实浏览器验证生成阅读页与编辑器预览均生成 strong 元素，同时确认多行公式仍正常渲染。
