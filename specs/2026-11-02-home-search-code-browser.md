# 首页统一搜索与参考代码库设计方案

2026-11-02 · 待评审

## 首页怎样使用

读者经常先搜一个函数名，再想知道它做什么。建议保留同一个输入框和其中的文字，在旁边用「普通搜索」「AI 搜索」两个互斥按钮切换。切换只改变处理方式，提交 AI 问题需要明确按下「提问」。这样读者能拿刚搜过的词继续提问，也不会因试切模式产生请求。

```text
[普通搜索 ●] [AI 搜索 ○]
[ 输入关键词或问题                              ] [搜索]
范围：全部知识库 ▾      匹配：文档名和全文 ▾
────────────────────────────────────────────────────
此处显示普通搜索结果，或依次显示问题、执行过程、流式回答
────────────────────────────────────────────────────
浏览知识库
参考资料    参考文献库 ｜ 参考网页 ｜ 参考代码库
```

| 操作 | 普通搜索 | AI 搜索 |
|---|---|---|
| 首次打开 | 默认选中，键入后沿用现有即时搜索；回车定位结果 | 切换后保留输入，显示回答模型、查询范围、历史 |
| 提交 | 沿用仓库过滤以及文档名、全文匹配 | 按「提问」或 Ctrl+Enter 发送；Enter 可换行，中文输入法选词期间不提交 |
| 看结果 | 保留结果分组，点击标题阅读文档 | 输入框正下方按轮显示提问、可折叠的执行过程、逐段正文与来源；就地追问 |
| 切换与返回 | 恢复上次结果和过滤条件 | 恢复本页对话；生成中切回普通搜索时显示「回答生成中」，可返回查看或取消 |

两种模式共享可编辑草稿。首轮提问成功发出后把问题放进对话，输入框留给追问。窄屏时模式按钮在上，输入框占满一行，模型和范围合并为一处设置入口。流式输出只在读者停留于答案末尾时跟随滚动。未登录时保留问题，提供登录入口；file:// 下默认普通搜索，AI 入口说明需要认证服务。

## 如何复用现有问答

首页目前由 setup_docsify.py 分别生成搜索框和 home-ai-question，后者调用 AIAssistant.open()。建议让首页统一输入组件根据模式调用普通搜索或问答控制器，移除首页重复输入和浮动 AI 入口。将 web/ai-assistant.js 的消息列表、范围树、模型选择、历史及消息操作绑定到传入的容器。首页挂载到正文，MD 阅读页继续使用现有面板。

一个会话只有一个活动请求。复用 POST /__ai/chat 的登录、CSRF、start/progress/delta/complete/error 和现有取消接口。普通搜索的重绘只更新自己的结果容器。用请求标识隔离迟到事件，响应结束、失败和取消都恢复输入状态，失败时保留部分正文。最终 Markdown 沿用现有净化渲染；复制、引用、撤回和恢复对首页回答同样生效。

## 参考代码库怎样浏览

首页「参考资料」新增独立的「参考代码库」卡片，进入 html/reference_code.html。入口先列出当前账号获准浏览的仓库，以代码根目录下的相对路径作为名称，例如 platform/trunk。进入后默认折叠子目录，左侧逐级展开，右侧显示文件内容、行号和面包屑。手机上目录改为可收起的抽屉。搜索结果跳到对应行，返回时恢复目录、搜索词和滚动位置。

建议借鉴 Elixir 的项目、版本和标识符交叉引用导航。首版提供当前可用快照，标签明确区分 SVN 已同步版本与本地目录。指定的 v3.7 示例页此次未能直接访问，参考依据为 Elixir 项目官方说明。[示例入口](https://elixir.bootlin.com/linux/v3.7/source) · [Elixir 项目说明](https://github.com/bootlin/elixir)

| 读者意图 | 建议交互与结果 |
|---|---|
| 找文件 | 搜文件名或相对路径，默认当前仓库，可收窄到当前子树；显示完整相对路径以区分同名文件 |
| 找一段实现 | 全文搜索返回文件、行号和命中片段，支持分页；点击后在代码页高亮该行 |
| 看函数在哪里定义、使用 | 点击标识符，分别列「定义候选」与「文本出现位置」。首期支持 C/C++ 常见声明，宏与重载保留多个候选；其他语言先提供精确词匹配 |
| 分享或让 AI 解释 | 行号生成可复制链接，例如 html/reference_code.html?repo=platform&path=src%2Fmain.c&rev=42#L80。提供「问 AI」回到首页，预填文件和行号，带入已授权仓库范围，由读者提交 |

目录覆盖方式沿用管理员开放的仓库根。每个根下的所有合规子文件夹递归提供浏览和检索；一个 SVN 工作副本只占一个仓库入口。普通本地目录也可由管理员登记。建议将“允许源码浏览”作为显式授权，管理员启用后才向登录读者展示，因为逐文件阅读和 AI 查询是两种不同的访问能力。普通搜索默认继续搜索文档，代码搜索入口位于参考代码库内，避免常见词产生大量源码结果。

## 服务端与索引

- 建议新增登录只读接口 /__code/repos、tree、file、search、symbol（后四项均在 /__code/ 下）。每次请求都根据 repo ID 重新核验授权，路径参数仅接受仓库内相对路径。沿用 contained_folder 的边界约束，另对文件本身校验真实路径，拒绝绝对路径、越界、链接、隐藏目录、凭据和私有运行文件。授权撤销立即影响旧链接及索引查询。
- 目录按需加载一层。文本源码按行窗口返回，超大文件支持跳至指定行；二进制文件只显示基本信息。所有源码作为文本转义呈现，语法高亮使用已有本地 Prism。
- 在 docs 之外的私有数据目录按仓库建立 SQLite 索引。记录相对路径、版本、文件摘要、行号及可检索词项。兼容 Python 3.6.8 与项目支持的 SQLite，基础路径检索不依赖 FTS。后台首次建索引，SVN 同步完成后更新，本地目录按变更增量更新；删除文件同步移除命中。索引构建中允许浏览，搜索显示可用版本和进度。
- 同一仓库的新索引完整写入后再切换版本。旧链接指向已替换的快照时提示版本已变化，并提供当前文件入口，避免用新内容冒充旧版本。多历史版本需后续单独配置快照留存。
- 源码与索引不写入公开的 search-index.json 或 offline-data.js。离线构建只复制页面、样式和脚本，参考代码页在离线环境提示连接认证服务。所有页面资源本地加载。

## 交付顺序和验收

1. **首页输入与内联回答。** 桌面和手机均只有一个问题输入框。切换模式保留文字且不发 AI 请求。提交后首段在输入框下出现，首页不弹侧栏。验证生成中切换、取消、登录后重试和离线普通搜索。
2. **代码库入口、目录与文件搜索。** 用两个含同名文件的授权仓库验收。能从首页进入任一仓库的三级子目录，按路径及全文找到具体行，并复制链接重新定位。验证无权限、路径越界、链接文件、二进制和大文件。
3. **标识符索引与引用。** 从调用点跳至定义候选，再回到引用处。同步后的新增、改名及删除都应反映在结果中；索引失败保留上一份完整结果并标出版本。在目标服务器上实测大仓库首建耗时、磁盘占用和查询延迟，再定索引限额。

评审重点是源码开放范围和版本留存。建议首版采用管理员逐库开放、仅浏览当前版本；这两个选择决定哪些读者能读取源码，以及旧行号链接能否长期复现。

## GNU Global 实施更新

参考代码库已使用 GNU Global 工具链。SVN 代码库导出到临时快照后先执行 gtags，成功后随快照一起发布 GTAGS、GRTAGS、GPATH。同步接口返回 indexStatus；gtags 缺失或执行失败时 SVN 同步仍可完成，搜索降级为受限文件检索。部署机须将 gtags 和 global 加入服务账号 PATH，版本由运维安装管理。

搜索优先调用 global 的路径检索或全文检索，返回路径、行号和片段；子目录浏览按需加载。索引文件禁止通过浏览接口读取。当前入口沿用 AI 已登记代码仓库，并要求网站登录。管理员开放 AI 代码库即同时开放登录用户的源码浏览，需要按该权限口径登记仓库。

已实施文件名/路径/全文搜索、源码行号、行号链接及版本变化提示，以及携带位置返回首页预填 AI 问题。首页已统一普通搜索与 AI 搜索输入框，切换保留文字，AI 回答在输入框下方流式显示。代码页使用独立目录与源码双栏，支持目录加载失败重试，会话刷新保留已展开目录和当前文件。首版文本文件上限 2 MB，文件扫描上限 10000 个，结果上限 200 条。离线参考代码页需要连接认证服务。

已提供 C 源码/头文件本地高亮及 GNU Global 符号定义、引用导航。点击标识符列出位置，支持返回跳转前的文件、行号和滚动位置。管理员可在源码页为本地目录重建符号索引。缺少索引时明确显示全文中的符号出现位置。历史版本留存及管理员独立源码授权开关待后续交付。
