# 编辑器站内文件引用与登录界面

编辑器工具栏新增“引用站内文件”，快捷键为 Ctrl+Alt+L（macOS 使用 Command+Option+L）。登录后可搜索 docs 中的 PDF、PPT/PPTX、Word、Excel、HTML、文本等静态资料，按文件名或路径筛选，每页 50 项。选择后在打开选择器时的光标/选区位置插入链接，支持撤销。

为避免 Docsify 将 HTML 链接改写为 hash 路由，插入 Markdown 支持的原始 HTML 锚点，包含 `target="_blank"` 和 `rel="noopener noreferrer"`。链接为站点根相对路径，编辑器预览根据页面 base URI 解析；无需写死域名。PDF/HTML 直接打开，参考文献目录下的 DOCX/XLSX/PPTX 使用现有本地 Office 预览页。旧版 DOC/XLS/PPT 等文件由浏览器打开或下载，不承诺在线预览。

搜索接口 `GET /__md/internal-files?q=关键词&offset=0` 要求登录，仅枚举允许的静态文件类型，跳过私有配置、代码、第三方 lib、回收站与反馈附件目录，不跟随目录链接。此功能引用已有文件，不上传或复制文件；离线或只读预览服务不提供实时搜索。

搜索采用 250ms 防抖并丢弃过期响应；输入变更立即清空旧结果，防止误选。原生 dialog 支持键盘导航，Esc 仅关闭文件窗口并恢复编辑焦点。

登录弹窗改为简明标题、账号输入区、横向记住登录选项与主要登录按钮；缩短说明并明确提权账号使用原 SVN 密码，提供可读错误状态、窄屏布局及弹窗内部滚动，不改变认证流程。

验证覆盖安全文件筛选、中文及特殊字符路径、Office 预览链接、匿名搜索拒绝、实际搜索插入、新标签页打开、快捷键和 Esc、桌面/手机登录布局及实际登录。使用 Python 3.6.8 构建与测试，运行时不增加外部依赖。
