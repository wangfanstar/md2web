# Claude 中转与代码库问答设计

日期：2026-10-30。状态：待实施。本方案替代 2026-10-29 个人 AI 配置存储方案的产品目标。

## 目标与现状

所有用户使用管理员维护的公共 AI 服务；用户只选择代码库并提问。服务器以 docs 为工作目录运行 Claude，Claude 读取选定的 docs/code 子目录与允许的文档，通过 linux_ai/win_soft/ClaudeRelay 访问模型。中转不会接管服务器代码检索。

当前 web/ai-assistant.js 有 PERSONAL_FIELDS、个人设置与浏览器直连逻辑，server/app.py 的 /__ai/config 支持个人配置读写，server/user_ai.py 将配置加密保存到 user_ai_configs。sourcePath 当前仅加入提示词，不能提供真实文件检索。linux_ai 是独立嵌套 Git 仓库，本次不变更其代码。

## 权限与交互

管理员设置页集中维护 Claude 可执行文件、模型、Windows 中转地址与令牌、超时、并发、文档范围、默认代码库。原有 AI 设置、统一设置弹窗和独立配置页均需遵循同一权限；后端管理员与 CSRF 双重检查，不能只隐藏按钮。

普通用户面板保留聊天、代码库下拉框、当前版本和来源引用；移除服务商、地址、Key、代理、系统提示词、个人上传与持久化检索范围设置。代码库选择属于本次问答参数，不是个人 AI 服务配置。首期登录后问答，访客显示登录提示；离线页面显示服务器问答不可用，不恢复浏览器直连。若需公开访客问答，另行增加管理员开关及限额。

公共配置接口只返回 enabled、模型显示名、可选代码库及默认项。秘密只保留在 Git 忽略的服务器私有配置或受保护的凭据存储，不进入 session、页面、离线资源、日志和错误响应。

## 调用与进程边界

浏览器发送问题、历史消息和 codeRepositoryId；服务器从公共配置解析执行参数，不采信客户端的模型、路径、环境变量或 URL。服务器生成请求 ID，校验登录、限额和代码库可用状态，再进入任务队列。

Claude 适配层使用参数数组和标准输入启动非交互进程，cwd 固定为 docs 的绝对路径，不使用 shell 拼接。子进程环境仅传必要项，中转令牌不得放在命令行。读取结构化输出并转换成本站 SSE：开始、文本增量、引用、完成、错误；具体 CLI 参数与输出协议以部署版本的能力探测和集成测试确认，不能假定所有版本一致。

每次请求独立会话，历史由服务端限制长度后传入，禁止全用户共享 Claude resume 会话。队列有全局并发、单用户并发、等待超时、执行超时与输出上限；取消或连接断开结束进程树并释放槽位。不在数据库锁中等待子进程或网络。

cwd 不提供隔离。生产部署必须用专用账户及操作系统沙箱限制文件读取，只暴露允许的文档和选定代码快照；禁用写文件、任意 shell、网络工具与交互式权限绕过。若目标 Claude 版本不能在该边界内完成检索，则由服务器提供受控只读检索结果给 Claude，不能仅靠提示词约束访问。仓库内提示内容不能改变服务端工具权限。

## 代码库配置与 SVN 更新

新增独立 codeRepositories 配置，不混用文档 repositories/mount。每项包含稳定 id、显示名、docs/code 下的单层目录名、SVN URL、凭据引用、目标 revision（HEAD 或数字）、enabled 与同步频率；根目录不可由客户端任意指定。拒绝重复目录、路径穿越、链接逃逸及嵌套工作副本。SVN 凭据复用既有认证服务的凭据解析与脱敏逻辑，不暴露给 Claude。

管理员提供新增、测试、首次拉取、更新至指定版本、健康状态与最近错误。普通用户仅列出可用库；请求固定选定库及实际 SVN revision。缺省使用管理员默认库，禁止静默换库；下线库与无默认项给出可操作错误。

SVN 网络访问复用 server/svn.py 唯一子进程入口。同步先在私有暂存区导出并校验，成功后在锁保护下切换到 docs/code/<目录>；失败保留旧版本。问答持有版本读租约，同步发布等待读者退出，避免一个回答混用多个版本；清理旧快照前检查引用。状态记录目标与实际 revision、时间和错误，问答来源显示实际版本。首期一次选择一个库，跨库问答后续扩展。

## 接口草案

- GET /__ai/public：脱敏公共状态与可选库，遵循登录策略。
- PUT /__admin/ai：管理员 + CSRF 保存公共配置，扩展现有白名单校验。
- GET /__admin/code-repositories：管理员读取配置及运行状态，秘密采用独立受保护管理接口。
- POST /__admin/code-repositories/<id>/sync：管理员 + CSRF，异步更新并返回任务号。
- POST /__ai/chat：登录 + 同源 + CSRF，接受 messages、codeRepositoryId，返回 SSE。
- POST /__ai/jobs/<id>/cancel：本人或管理员 + CSRF 取消。

个人 /__ai/config 的 PUT/DELETE 停用并返回 410 ai_personal_config_retired；GET 返回迁移说明，不返回旧秘密。代码库不存在、同步中、执行不可用、限额、超时、中转失败分别返回稳定错误码和中文说明；流开始后的错误使用 SSE error 事件。

## 迁移与私有目录保护

先部署服务端权限与公共脱敏，再切换前端，移除 PERSONAL_FIELDS 加载/保存、个人 JSON 导入、浏览器直连和访客配置回退。普通用户保存接口即使使用旧前端也不能生效。管理员配置仍写入当前私有 JSON 方案，并保持配置版本冲突检测。

旧 user_ai_configs 不导入公共配置；停止读取，提供管理员迁移清理操作并记录清理数量，不记录内容。用户浏览器下一次打开时删除已知个人/访客 AI 配置 Key，聊天历史单独处理；不能声称可远程清除从未再访问的浏览器。停止在 session 下发旧 Key。

在启用代码库前，为 docs/code 与同步暂存区加 Git 忽略、静态路径拒绝及备份排除；覆盖认证服务和 --preview，两者请求源码均返回拒绝。构建不扫描、不打包代码库，不将 SVN 元数据、令牌或源码嵌入离线数据；构建不得清理代码目录。引用只返回库 ID、相对路径、行号及版本，通过受权接口查看，不能返回可公开访问的静态源码 URL。

## 实施阶段与验收

1. 公共配置收敛：后端权限、session 脱敏、前端移除个人入口、旧配置迁移。
2. 代码库管理：私有目录防护、SVN 导出和版本锁、默认与可选库界面。
3. Claude 适配与 Windows 中转：能力探测、隔离、队列、SSE、超时取消、错误与引用。
4. 部署联调：Linux Claude → Windows relay → 模型往返，用固定代码样例检验真实文件检索与版本差异。

验收覆盖普通用户伪造写配置、旧个人 Key 不再使用、公共接口无秘密、代码路径穿越与链接逃逸、静态/离线/备份泄漏、不同用户会话隔离、同步与问答并发、同步失败保留旧版本、断流取消及中转故障。用两个 SVN 库的不同 revision 验证选择结果和引用一致。Python 修改仅以 Python 3.6.8 测试及兼容检查验收，前端执行相关 Node 和浏览器回归。真实中转测试需在已配置部署环境执行；未执行不得标记通过。

## 2026-10-30 实施与部署

已实现：管理员公共 AI JSON 与代码库配置；普通用户无个人配置/上传入口；旧个人接口 410；会话仅公开模型显示名和启用状态；旧个人数据可由管理员清理；浏览器旧配置再次访问时清除。只读预览不再提供任意 AI 转发。

AI 面板的管理员「配置」入口可管理 `ai.claude`：

```json
{
  "baseUrl": "http://WINDOWS_RELAY_HOST:8787",
  "apiKey": "填写私有中转令牌，不提交 Git",
  "model": "填写中转支持的模型",
  "claude": {
    "enabled": true,
    "executable": "claude",
    "timeoutSeconds": 120,
    "defaultRepository": "firmware",
    "repositories": [
      {"id": "firmware", "name": "固件代码", "folder": "firmware", "url": "https://svn.example.com/firmware", "revision": "HEAD"}
    ]
  }
}
```

先安装独立 linux_ai 仓库提供的 Claude，并启动 Windows 中转。可执行文件须支持 `--bare`、`--no-session-persistence`、`--tools`、`--strict-mcp-config` 和 JSON 输出；以本机 `claude --help` 和 [官方 CLI 文档](https://code.claude.com/docs/en/cli-reference) 核对，旧版不支持时明确升级，不降级为绕过权限。服务账户需有 docs/code 写权限用于 SVN 同步；问答期间 Claude 不启用任何文件、命令或 MCP 工具，不加载项目设置与 hooks，不保存 Claude 会话。

管理员保存默认 SVN 凭据后，在配置中填写代码库并保存，重新打开面板点击「同步」；也可使用 `code-<id>` 的单独凭据引用。HEAD 在导出前解析为固定 revision；代码导出到暂存区，拒绝链接，发布失败恢复旧目录，回滚失败保留备份路径。问答与同步共用互斥锁，忙碌时返回可重试错误。

普通用户登录后，在 AI 面板选择代码库提问；服务器限量扫描 UTF-8 文本、提取有行号的匹配片段并补充文档资料，Claude 只接收这些片段与最多 9 条对话消息。一次请求绑定一个实际 SVN revision；回答附代码路径与版本。检索上限为 10,000 个文件、单文件 256 KB、代码片段 24,000 字符和文档片段 12,000 字符；因此不能保证全仓库语义搜索完整性，未命中时应明确资料不足。

当前交付的运行边界：全局同时执行 1 个问答或同步，多余任务立即返回 busy；同步为管理员手动同步，SVN 调用沿用既有超时；SSE 提供任务号、心跳、完成或错误事件，回答在 Claude 完成后一次返回，支持显式取消与断开连接取消。自动同步调度、并发任务队列及模型 token 增量事件尚未实现，不属于本次已验证能力。修改 CLI 参数前必须保留禁用工具与不持久化的边界。

验证：Python 3.6.8 全量回归、相关前端 Node 测试、离线构建，以及 Edge + Playwright 普通用户/管理员回归。模型调用通过假进程验证工作目录、真实片段和工具禁用；未使用生产令牌发送代码，实际 Linux → Windows 中转 → 模型端到端联调需部署配置后执行。
