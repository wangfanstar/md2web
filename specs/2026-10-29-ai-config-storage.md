# 公共 JSON 与个人 SQLite AI 配置

公共设置沿用运行配置和当前 `docs/html/md2web_config*.json` 方案的 `ai` 段。管理员可在配置页 AI Tab 查看/编辑专用 JSON，应用到表单后保存；服务设置弹窗也保留 AI JSON 编辑器，AI 面板可显式保存公共默认值。个人保存默认不会更新公共配置。

数据库升级至 v14，新增 `user_ai_configs`：以用户主键隔离记录，`config_secret` 保存使用服务器 `security.secretKey` 加密的配置 JSON，`updated_at` 保存更新时间。该表和私人密钥不得进入公开仓库。现有账号/草稿数据不改写。

`GET/PUT/DELETE /__ai/config` 只使用当前会话用户 ID；不接受客户端用户 ID。读取要求登录，写入/删除另需 CSRF。字段白名单包含公共 AI 字段、scope 和 uploads；个人检索文档总量不超过 512 KB，配置请求不超过 2 MB。读取解密失败不会自动覆盖原记录。

登录后从 SQLite 加载个人配置，无个人记录时继承公共默认值；个人配置优先。账号切换清空内存中的旧个人配置，用加载代次拒绝过期响应，并按队列保存；加载完成前不允许写入，避免默认值覆盖旧配置。退出后使用独立访客本地配置。旧的共享 localStorage 不自动导入，通过显式导入按钮填入并检查后保存。

登录用户不再将个人 Key 写入浏览器配置缓存；接口参数、资料范围和个人检索文档一并进入加密记录。访客和 `file://` 离线模式仍使用独立浏览器配置。对话历史的既有浏览器存储方式不属于本次个人配置存储变更。

部署后重启服务自动迁移数据库，重新打开页面。备份/恢复 SQLite 时同时保留服务器私有配置密钥，才能解密个人设置。

回归覆盖账号隔离、登录/CSRF、加密存储、非法字段/数值/大小、清除个人设置、同账号跨浏览器恢复、公共 JSON 编辑与温度 0 保留。

验证结果：Python 3.6.8 全量 600 项通过（跳过 1 项），JavaScript 全量 151 项通过；个人配置/公共 JSON 浏览器回归与配置页回归通过，前端语法检查和离线构建通过。浏览器回归还覆盖旧配置确认迁移后移除共享缓存、过期账号响应隔离、退出时清空公共 JSON 编辑框中的 Key。
