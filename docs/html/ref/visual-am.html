从观察点换算到 PTP 参考面

以发送方向为例，若 PHC 在 MAC 边界记录时间，而目标参考面位于其下游，则换算需要加上两者间的发送延迟。接收方向应按参考面和采样点的先后关系确定符号。补偿量取决于 AM 相位、lane 映射与实际流水线。

RX 通过 AM 识别 lane 并进行 deskew。启用 RS-FEC 的 PHY 还需考虑码字映射与编解码延迟。200G/400G 的转码、AM 组及 FEC 顺序见 Visual PCS 的高速通路。
