L1 主链路

  • ① HPP 入向MACW RX → MACI RX → PIRX → Parser/VLAN → L2 → L3/SPP → ACL → PITX
  • ② MMU / TMPITX → MIRX → MCBM → TLSBC → XMMU → TM → MITX
  • ③ HPP 出向MITX → PERX → PETX → MACI TX → HPP NOC → Mirror → MACW TX
  • ④ CPP 控制AUX/CPIS → CPP MACI RX → CPP Ingress → CPP MIRX → CPP MCE → CPP TM → CPP MITX → CPP Egress → CPP MACI EG → AUX/CPIS
  • ⑤ AUX / 主机AUX MAC / PCIe / CPIS ↔ CPP 入向 / 出向
  • 跨 DIEPITX / CPP Ingress → UCIe E / Spare UCIe S

操作：左键按住拖动平移视图，右键拖动旋转，滚轮 / 双指缩放；点击 die 或模块卡片进入下一层。
左侧「固定图层」可锁定当前层级：锁定后缩放只改变远近，不会自动切换视图；选「自动」恢复按缩放切换。
「端口映射」按 HPP0-3 / MAC0-15 / TM0-7 展示 port-id 对应关系，点击 MAC/TM 查看 mi_id、mc_id 与端口范围。
「子系统」按 pzz_all.md 展示 29 个子系统的 3D 架构与流程阶段，点击卡片查看需求特性与接口。
「流控链路」绘制 MACW / MACI / MIRX / AQM / TM / MITX 之间的 PFC、CBFC、credit 与统计链路，可按类型过滤；点击模块查看交互与查询命令。
「转发路径」按 入口身份 / Ingress HPP·CPP / 本 DIE Fabric / Cross-DIE·Egress / 出口 五段展示全部模块，支持 本 DIE / 跨 DIE、AUX / HPP / CPP / Mirror 分类高亮；默认显示全部路径箭头，点击箭头高亮该路径并显示信息，点击模块可查看统计/状态查询命令（CPP 取自 CppPacketIngree2Egress.png）。
「报文路径」按 10 类报文展示全部 31 个模块（Ingress / Lookup / MMU / Egress / 隧道分支），点击报文类型高亮对应模块，点击模块查看输入/输出/本地处理与查询命令。
「架构图」可查看 mermaid_code 下的流程图。
放大到某个 die 后会自动展开内部结构；继续放大可切换 MACI RX / TX、MMU、MIRX / MITX、PITX 内部视图。
L1 视图按主链路分为 5 条泳道，箭头颜色对应链路类型，图例中按顺序列出完整模块链；悬停模块显示名称、输入/输出与本地处理。
