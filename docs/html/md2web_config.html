md2web 仓库配置

默认列出 docs/md 下的所有文件夹、入口页链接、最新更新（作者/时间）与仓库大小； 勾选「配置 SVN」才会展开 SVN 地址、更新频率、只读/允许合入等设置（不勾选表示本地模式，不连接 SVN）。 保存后站点会自动重建：每个仓库生成一个入口页 index_<仓库名>.html，根目录 index.html 为分组总览。

管理员登录

默认管理员账号 admin / admin（仅用于本页与站点设置，合入 SVN 时需要另外的 SVN 账号）。

配置方案

默认内置三套可选配置：md2web_config.json（主配置）、md2web_config_default.json（默认配置）、md2web_config_backup.json（备份配置）；缺失时按当前配置自动生成快照，可在下拉中切换并分别保存。

修改后点击「保存配置并重建站点」，自动同步当前 JSON 并保留上一版。切换方案立即生效，重启继续读取默认方案；不会删除仓库文件。同步账号、密码及 AI Key 按明文保存在方案中，仅管理员接口可读；端口、数据库位置和服务密钥单独保留。

更新代码时请保留 docs/html/md2web_config*.json、config/server.local.json 和 data/。JSON 不受构建覆盖，并在 data/config-profiles/ 自动备份。

状态说明（登录管理员后自动检查，也可点「检查」/「检查全部状态」）：

  • ✔ 正常：远端可访问且本地目录存在（显示当前版本 r 号）。
  • ✖ 认证失败 / 无法连接 / 路径不存在 / 证书错误 / SVN 客户端不可用：检查 SVN 地址，或在下方「默认同步凭据」统一配置账号，或在仓库明细里单独填写同步凭据。
  • ⚠ 同步异常 / 本地内容缺失：点「修复」执行 svn cleanup 并强制重新拉取远端内容（覆盖同名文档，不删除本地新增文件）。
  • ✖ 仓库身份变化（远端库被重建，UUID 不一致）或修复仍失败：点「删除重建」——本地目录（含未提交修改）移入 data/trash 后重新绑定仓库身份并完整拉取。
  • ⚠ 存在冲突：有文档正在编辑（草稿），同步时已跳过；在编辑器中查看「远端差异」并合并后提交。
  • 「创建并拉取」在目录不存在时自动创建 docs/md/<文件夹> 并从 SVN 导出内容。
  • 「来源类型」分三种：SVN 库（地址/频率/账号）、软链接（填写目标目录，可检查/创建/移除链接，默认且强制只读，网页不会修改目标目录）、本地文件夹（无需地址与同步配置）。未配置的文件夹按实际目录自动识别。
  • 「更新频率（秒）」留空使用全局默认（设置 → SVN 与仓库），填 0 表示不自动同步。
  • 不勾选「配置 SVN」的仓库按本地模式（SQLite 主库）保存，不做 SVN 检查；「移除配置」清空该文件夹的仓库 ID 与地址。

默认同步凭据（SVN 账号）

用于统一同步所有文件夹的 SVN 库：仓库没有单独配置凭据时自动使用这里的账号。 保存前会先用 SVN 认证路径校验用户名与密码（必须是强制账号密码认证的路径），校验通过后明文保存到当前 JSON 方案，并兼容保留数据库加密副本。

正在读取…

仓库明细里单独保存的同步凭据优先于默认凭据；未配置默认凭据时回退到环境变量同步凭据（设置 → SVN 与仓库）。

网站数据备份（SVN）

把网站数据（默认 docs/，含生成的页面、搜索索引与源文档）按频率定时合入到指定的 SVN 库； 凭据优先使用下面单独设置的备份账号（明文保存到当前 JSON），未设置时回退到「默认同步凭据」或环境变量同步凭据。

备份状态：（未启用或未检查） 「修复工作副本」执行 svn cleanup，修不好会自动移入 data/trash；「删除重建工作副本」会移入 data/trash 后立即重新检出并备份一次。

账号切换与验证（SVN）

SVN 认证路径用于登录时验证账号合法性：必须是强制账号密码认证的路径（允许匿名访问的会被拒绝）。 例如只读的 https://svn.example.com/svn/accounts/auth-check/。修改路径只失效 SVN 用户会话，管理员会话保留； 「默认同步凭据」（上方面板）也用该路径校验账号。

「验证账号」只调用 SVN 认证路径校验用户名与密码（不改变当前登录）； 「验证并切换为该账号」验证通过后用该账号重新登录本页（SVN 账号不是管理员，页面会变为只读，可再用管理员账号切回）。

AI 默认配置

随当前 JSON 方案保存。SVN 账号验证使用上方「SVN 认证路径」，默认同步账号及各库专用账号也会写入当前方案。AI 默认值提供给已登录用户，个人 AI 设置可覆盖默认值。

仓库回收站

恢复时一并还原仓库配置和本地资料。SVN 远端内容及软链接目标始终保留。
