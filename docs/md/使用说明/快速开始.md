# 快速开始

欢迎使用 md2web。把 Markdown 放进 `docs/md/`，运行构建脚本即可生成完全离线的文档站。

## 首页浏览与搜索

打开 `index.html` 后，可按仓库卡片进入资料库，也可直接搜索文档名与全文。向下浏览较长的仓库列表或搜索结果时，搜索工具栏会固定在页面顶部；搜索框、仓库范围、搜索模式和常用入口仍可操作，无需先滚回页面开头。窄屏上工具栏会自动换行，仓库下拉菜单可独立滚动。

搜索默认覆盖全部仓库，结果按「文档名匹配」和「全文匹配」分组。可用「仓库」下拉框多选搜索范围，或用「模式」只查文档名/全文；滚动页面不会清空输入和筛选条件。

## 阅读区工具栏

每篇文档右上角都有一排按钮：

- **复制链接**：复制当前页面的链接地址（含 `#/` 路由，可直接分享给他人）
- **复制本页内容**：复制当前正文及格式，供 Word、邮件等富文本编辑器粘贴；在 Word 中可选「保留源格式」。标题、章节序号、表格、列表、文字颜色与代码格式会保留，公式和图表按图片复制（不是 Word 可编辑公式）。此按钮在文档、概览与目录页均显示；复制不包含导航和操作按钮。若部分图片或图形无法内嵌，按钮会提示；纯文本接收软件会使用正文文本。
- **复制 SVN 链接**：当前文档属于已配置 SVN 仓库时显示，复制仓库地址与文档相对路径
- **编辑 MD**：打开双栏编辑器——左侧 Markdown 源码按格式分色，右侧实时预览（Mermaid、PacketDiag、KaTeX 公式、代码高亮）；左侧固定大纲导航默认显示，点击章节会同时定位源码与预览；支持撤销/恢复、上传图片与附件、文字颜色和表格行列选择器。登录后 `Ctrl+S` 按文档来源处理：本地文件夹或未关联 SVN 的文档直接「保存到服务器」；SVN 文档先保存个人草稿，再通过「提交 SVN」写回仓库。
- **下载 MD**：下载当前页面对应的 Markdown 源文件
- **下载本页**：把当前文档导出为自包含 HTML（含图片、图形与目录，可离线转发）
- **宽屏阅读** / **隐藏序号**：切换阅读布局与标题编号

编辑器常用快捷键：`Ctrl+B` 加粗 · `Ctrl+I` 斜体 · `Ctrl+K` 链接 · `Ctrl+M` 行内公式 · `Ctrl+Shift+M` 公式块 · `Ctrl+Alt+1/2/3` 标题 · `Ctrl+Shift+U`/`Ctrl+Shift+O` 无序/有序列表 · `Ctrl+Shift+K` 任务列表 · `Ctrl+Shift+C` 代码块 · `Ctrl+Shift+G` Mermaid · `Ctrl+Shift+D` PacketDiag · `Ctrl+Shift+T` 表格行列 · `Ctrl+Alt+K` 文字颜色 · `Ctrl+Shift+H` 大纲导航 · `Ctrl+S` 保存到服务器/暂存草稿 · `Ctrl+Shift+S` 另存为 · `Ctrl+/` 全部快捷键。

> 草稿与提交需要登录认证服务（`python serve.py`）；局域网其他机器访问时同样可以登录编辑，权限由所在仓库的「允许合入 / 允许在线修改」开关决定；`file://` 双击模式为离线只读，编辑器只能下载或保存到本地文件。

左侧栏顶部还有「绘图预览」入口（<a href="lib/plot-playground.html" target="_blank" rel="noopener">lib/plot-playground.html</a>），可在线试写 Mermaid / PacketDiag 并下载图片。

## AI 助手

右下角「AI 助手」按钮（或 `Ctrl+Shift+A`）打开对话面板：它会先在本地 `search-index.json` 中检索相关章节，再把资料片段与问题一起发给您配置的大模型，回答下方列出引用来源，点击即可跳转。

配置入口在**左侧栏顶部的 `AI 配置` 图标**（对话面板右上角「⚙ 配置」同样可打开），包含：

- **服务商与密钥**：OpenAI 兼容 / DeepSeek / Ollama 本机 / Anthropic / 自定义，填写接口地址、模型、API Key、温度、系统提示与请求方式，点「保存并测试」验证连通性
- **资料范围**：按文件夹/文档勾选，回答只依据所选资料（不勾选 = 使用全部文档）
- **上传文档**：可选择本机的 `.md` / `.markdown` / `.txt` 加入检索（单个 ≤ 256 KB、合计 ≤ 512 KB，仅保存在浏览器 localStorage，不会上传或提交到仓库）；上传文档会出现在资料范围的「upload://」分组中
- API Key 只保存在浏览器 localStorage，不会写入仓库或上传服务端；公开仓库请勿把 Key 提交进任何文件
- 请求方式默认「自动」：浏览器直连失败（通常是跨域）时自动改走本机 `serve.py` 的 `/__ai/chat` 代理（仅本机可调用）
- 完全离线（双击 `index.html`）时检索仍可用，但调用模型需要网络，且只能直连、不能走本机代理
- 快捷动作：「总结本页」「文档概览」「解释选中」（选中正文文字后点击）

## 数学公式

行内公式用 `$...$`，独立公式块用 `$$...$$`，由 KaTeX 离线渲染：

行内：$a^2 + b^2 = c^2$

$$
\int_{-\infty}^{+\infty} e^{-x^2}\,\mathrm{d}x = \sqrt{\pi}
$$

公式块支持跨行和空行，TeX 中的转义会保留。例如文本下划线写成 `\_`，「小于等于」用 `\leq`（不是 `\leg`）：

$$
\text{S\_VC\_CU}[x] + \text{pktCredits}
\leq

\text{S\_VC\_CL}[x]
$$

## 仓库配置与登录状态

首页「仓库配置」打开 <a href="html/md2web_config.html">站点管理页面</a>，分为「仓库管理 / 账号与权限 / 备份与恢复 / AI 设置 / 缓存与性能 / 配置方案」六个 Tab。仓库概要表点「编辑」打开详情抽屉；普通表单修改可跨 Tab 保留，通过底部「保存全部修改」统一保存，也可先查看差异或放弃修改。同步账号与密码需要在对应位置单独验证保存；配置冲突时可读取服务器最新配置进行比较，未保存内容会保留。

需要跨服务重启继续登录时，请在登录框勾选「保持登录」；普通会话在服务重启后需重新登录。「记住此设备的用户名」只用于预填用户名，不代表已登录。页面会定期复核会话，回到页面时也会校验；会话失效、网络异常或校验超时会清除旧登录显示。重新登录后可继续处理编辑器中尚未保存的文字。

更新代码并重启 `serve.py` 时，默认站点会自动同步最新前端 JS/CSS；即使使用 `--no-build` 关闭文档自动重建，这一步仍会执行。同步不会改写服务器上的仓库目录；更新后刷新浏览器页面。纯静态部署或 `file://` 分发仍需执行离线构建并复制完整 `docs/`。

## 目录约定

- `docs/md/` 是唯一需要维护的目录，可自由创建子文件夹
- 图片无需登记，放在文档旁边或任意位置，用相对路径引用即可，例如 `![](images/flow.png)`；编辑器上传的图片会保存到文档同级 `images/`
- 附件放在文档同级 `附件/`，编辑器「上传附件」会自动插入 `[文件名](附件/文件名)` 链接
- 上传大小：PDF、Word、Excel、PPT、编辑器图片/附件与反馈附件默认单文件不超过 500 MB（1 MB = 1024 × 1024 字节）。管理员可在配置页「缓存与性能 → 上传大小」设置 1–500 MB，点击「保存全部修改」后立即生效并保存到当前 JSON 方案；参考文献多文件上传会自动分批，失败时显示具体文件与原因。
- 引用网站已有资料：编辑器点击「引用站内文件」或按 `Ctrl+Alt+L`，输入文件名或路径搜索 docs 中的 PDF、PPT、HTML 等文件，选择后自动插入新标签页链接。参考文献中的 DOCX/XLSX/PPTX 使用本地预览；旧版 Office 文件可能由浏览器下载。该功能需要登录网站服务，不会重新上传文件。
- 引用站内 Markdown：点击「站内文档链接」或按 `Ctrl+Alt+Shift+L`，先按文档名称或路径搜索并选择文档，再搜索该文档的章节标题；可点击「插入整篇文档」，或选择具体标题插入新标签页链接。「返回文档列表」会保留之前的搜索词和页码。同名章节使用网站索引中的独立 ID。新增文档或修改标题后需要完成网站自动重建，搜索结果才会更新。
- 编辑器顶部的保存、另存为、下载和关闭按钮固定为一组，状态提示单独显示；窄屏可横向滚动操作按钮，关闭按钮保持可见，不会因提示文字变化换行。
- 构建只处理 `.md` 文档；图片与附件由浏览器直接加载

## 构建与预览

```
python setup_docsify.py
python serve.py
```

也可以直接双击 `docs/index.html` 浏览（file:// 模式）：`docs` 根目录只保留总览页 `index.html`，其余页面与数据在 `docs/html/`；点总览里的文件夹卡片进入 `docs/html/index_<文件夹>.html`，每个入口页都内嵌了 Markdown 与搜索快照，离线只读，保留搜索、图形、公式与下载能力。

## 登录与编辑权限

默认 `python serve.py` 启动**认证编辑服务**（匿名可读、登录后可编辑）；`python serve.py --preview` 是只读预览，不提供任何写接口。

```
python3 -m pip install --user --no-index --find-links server/wheels -r server/requirements.txt   # 离线包（推荐；非 root 加 --user）
python3 -m pip install --no-index --find-links server/wheels -r server/requirements.txt            # 离线包（有写权限的账号）
python3 -m pip install -r server/requirements.txt                                                  # 或联网安装（仅服务机需要）
python3 serve.py                                     # Linux 推荐用 python3（3.6.8+ 全功能）
python serve.py                                      # Windows / 默认启动认证编辑服务（配置不存在会自动生成）
python serve.py --preview                            # 只读预览（无写接口）
python serve.py --bind 127.0.0.1                      # 仅本机访问（默认监听所有网卡，局域网可访问）
./start_linux.sh                                   # Linux：默认后台启动（日志 data/serve.log）
./start_linux.sh --stop                            # 停止后台实例（按 pidfile）
./start_linux.sh --restart                         # 强制重启：先 git pull --ff-only 更新代码，再结束占用端口的进程后启动
./start_linux.sh --update                          # 启动前更新代码（仓库有新版功能时用它）
./start_linux.sh --update --no-update              # 跳过代码更新（等价 MD2WEB_NO_UPDATE=1）
MD2WEB_GIT_PROXY=http://127.0.0.1:7890 ./start_linux.sh --restart   # 网络受限（直连 github 被重置）时走代理更新
MD2WEB_UPDATE_ONLY=1 ./start_linux.sh --update     # 只更新代码不启动（配合部署脚本）
sh start_linux.sh                                   # 若报 No such file or directory（CRLF/权限）：用 sh 运行可自动去 CR
sed -i "s/\r$//" start_linux.sh && chmod +x start_linux.sh   # 或手动修复后继续用 ./start_linux.sh
./start_linux.sh --status                          # 查看状态与进程（md2web-serve）
./start_linux.sh --foreground                      # 前台运行（Ctrl+C 停止）
```

> 重启/更新说明：`start_linux.sh` 只运行**当前工作区**的代码，不会自动同步远端。`--restart` 与 `--update` 会先 `git pull --ff-only` 再启动（前端生成物随提交同步，因此通常无需额外构建；`--rebuild` 可强制重建站点）。服务运行时会自动重建 `docs/`，这些生成物的本地改动会先还原、拉取后按本机配置重建，不会挡住更新。更新失败时只打印警告并继续用现有代码启动，常见原因是 `docs/` 之外的未提交改动、部署目录不是 git 工作副本，或直连 github.com 被重置——按提示走代理或先手动 `git pull`。

局域网访问：服务默认监听所有网卡，启动日志会打印「局域网访问: http://<服务器IP>:8882」，同事直接用该地址即可打开；打不开时先放行防火墙端口：RHEL/CentOS 7 执行 `sudo firewall-cmd --add-port=8882/tcp --permanent && sudo firewall-cmd --reload`，Ubuntu 执行 `sudo ufw allow 8882/tcp`（启动时会检测 firewalld/ufw 并提示）。**机器有多个 IP、只有部分 IP 能打开**时按顺序查三点：① 监听地址——`ss -lntp | grep 8882` 必须是 `0.0.0.0:8882`，若显示某个具体 IP 说明 `--bind`/配置 `server.bind` 把它限死了（改成 `0.0.0.0`）；② 地址类型——只有物理网卡（`eth0`/`ens33`/`bond0`）的地址才能从外部访问，`docker0`、`virbr0`、`tun`/`br-*` 等虚拟网卡地址外部没有路由；③ firewalld 按 zone 绑网卡——`sudo firewall-cmd --get-active-zones` 列出多个 zone 时**每个 zone 都要放行**（`sudo firewall-cmd --zone=<zone> --add-port=8882/tcp --permanent && sudo firewall-cmd --reload`），只放默认 zone 会导致另一个网卡的 IP 打不开。启动横幅会列出全部可用地址并标注虚拟网卡；只监听单个 IP 时会直接提示哪些地址打不开。只允许本机使用时用 `--bind 127.0.0.1`。局域网内任何人都能看到登录页与文档，请务必修改默认管理员密码。

启动后刷新页面：

1. 侧栏顶部「设置」→ 用管理员账号登录（首次为 **admin / admin**，登录后请立即在窗口底部修改密码）。
2. 在「SVN 认证路径」填入管理员准备的路由（必须是**强制账号密码认证**的路径，可点「测试认证路径」验证；允许匿名访问的路径会被拒绝）。
3. 在「仓库映射」中填写 docs 目录与 SVN 地址（按目录段最长前缀匹配，如 `md/硬件设计` → hardware 库）。
4. 在「默认同步凭据（SVN 账号）」中填入统一的 SVN 同步账号/密码（保存前会用认证路径校验并加密入库）：没有单独配置凭据的仓库同步时统一使用它；某个仓库需要不同账号时，在它的明细行里填写「同步账号 / 密码」并点「保存凭据」，该凭据优先于默认凭据。
5. 按需填写「AI 助手」默认值（接口地址/模型/Key，会下发给所有登录用户），保存即可生效，无需重启。

管理员打开「设置」还能看到**使用情况**（按 IP/账号的登录记录、账号使用量、用户总数、详细操作记录）与**文档统计**（每个文档的大小/更新时间/更新次数、文件夹大小、文档增删记录，点击表头可排序）。

「设置 → 仓库映射」可为每个文件夹分别设置 SVN 库与**更新频率（秒）**：服务会按频率自动拉取远端更新；正在编辑（有草稿）的文档不会被覆盖，编辑器会提示先合并并可查看「远端差异」，提交成功后展示本次差异。

编辑器左侧目录默认显示，点击章节会同时把源码与右侧预览定位到该处；「设置」窗口按 AI 助手 / SVN 与仓库 / 账号 / 信息查询 分 Tab 显示。
提交时会把文档里引用的 `images/` 图片与 `附件/` 文件一起存档到 SVN（审阅面板会列出将一并提交的图片与附件）。

仓库与站点结构：`docs` 根目录只保留总览页 `index.html`，其余页面与数据都在 `docs/html/`——每个文件夹一个入口页 `html/index_<文件夹或仓库名>.html`（独立搜索索引；只读/禁止合入的仓库不能提交），`html/index_all.html` 为全部文档合并视图；仓库配置在 `html/md2web_config.html`（管理员登录后可改地址、目录映射、更新频率、分组与权限，可在「默认同步凭据」统一设置同步账号或按仓库单独保存凭据，并可用「创建并拉取」自动创建目录并下载 SVN 内容）。

之后：

- 匿名读者仍可浏览、搜索、下载；docsify 文档页在侧栏显示「登录」，总览/配置/反馈/回收站/绘图预览等独立页在右上角显示固定的「登录」入口。
- 编辑者用**自己的 SVN 账号密码**登录（服务端通过认证路径验证；口令先校验，成功后以本机密钥加密保存在服务端数据库，提交与查询直接复用，换密码后重新登录会自动更新；旧版 svn 客户端会回退到命令行参数传口令）。
- 登录后打开编辑器，`Ctrl+S`（或「保存」按钮）按文档是否有 SVN 库区分：
  - **没有 SVN 库**（所在文件夹未配置仓库，或配置为本地模式）：按钮显示「**保存到服务器**」，一步把内容写入 `docs/md` 并重建站点，关闭编辑器后页面自动刷新即可看到更新；服务器上的文件被外部改动时会提示冲突并拒绝覆盖。
  - **有 SVN 库**：按钮显示「**本地暂存**」——保存的是带版本号的个人草稿（其他标签页或本人更新会让旧版本保存返回冲突，不会覆盖），只存在本机服务器、不会写 SVN；工具条提供「历史」（草稿版本列表，可载入任一版本）、「差异」（已发布版本 ↔ 当前草稿的统一差异）、「载入最新」「放弃草稿」。确认无误后点「**提交 SVN**」写入仓库。
- **离开提醒**：只要还有未提交 SVN 的本地暂存（草稿），或编辑器里有未保存的修改，关闭/刷新/离开网页时浏览器会弹确认，避免辛苦编辑的内容丢失。
- **插入图片 / 上传附件**：工具栏「上传图片」「上传附件」可多选文件，也可在源码区直接 `Ctrl+V` 粘贴剪贴板图片、把文件拖入编辑器（图片自动走 `images/`，其他文件走 `附件/`）。登录后图片保存到**当前文档同目录的 `images/`**（命名 `<文档名>-<时间戳>-<序号>.<扩展名>`）并插入引用，附件保存到同目录的 `附件/`（沿用原文件名、重名加序号）并插入 `[文件名](附件/文件名)`；`file://` 离线模式改为内嵌 data URL 或下载。
- **文字颜色与表格**：`Ctrl+Alt+K` 打开颜色面板（生成 `<span style="color:…">`，预览与站点都生效）；`Ctrl+Shift+T` 用行列选择器插入 1–8 行列的表格。
- **查找与替换**：源码区 `Ctrl+F` 打开查找、`Ctrl+H` 打开替换；支持**大小写敏感 / 整词 / 正则**，显示命中计数，`Enter` / `F3` 跳到下一个（`Shift+Enter` / `Shift+F3` 上一个），「全部替换」一次完成，替换结果可用 `Ctrl+Z` 撤销。
- **没有 SVN 库也能保存**：所在目录未关联仓库或为本地模式时，用「保存到服务器」直接写回 `docs/md`（草稿仅用于有 SVN 库的文档）；有 SVN 库时提交 SVN 会把新文件加入仓库。
- **提交 SVN**：编辑器右上角「提交 SVN…」→ 填写提交说明 → 审阅面板显示目标库、精确文件与统一差异 → 点「确认提交」用**自己的 SVN 账号**提交；成功后站点会自动重建。提交只包含这篇文档，不会夹带其他文件夹或其他人的改动；远端基线过期时会明确报错而不是覆盖。「SVN 日志」可按当前账号查看目标库日志。
- **管理员**使用本机账号（默认 `admin / admin`）登录后同样可以本地编辑；提交时提示输入一次 SVN 账号，验证通过后会加密保存到服务端数据库，后续提交可复用。
- 普通会话默认 8 小时有效、闲置 30 分钟失效，服务重启后需重新登录；勾选「保持登录」的有效会话可以跨重启。
- 写接口全部经过登录 + CSRF 校验；源文件写回使用版本校验，不再有"再次保存强制覆盖"。
- 修改 SVN 认证路径会让已有 SVN 用户会话失效（管理员会话保留以便继续配置）。

> 阶段一（登录与只读边界）、阶段二（个人草稿、版本历史、差异）与阶段三（多库提交、私有工作副本、外部同步）已实现。工程师生成本地编辑与 SVN 提交的习惯不受影响，网站也不采集本地编辑过程。

## 界面小技巧

- 阅读区右上角的按钮行（复制链接 / 查看源码 / 编辑 MD / 下载 MD / 下载本页 / 显示序号）在向下滚动时会**固定在顶部**。
- **序号设置**：点击正文序号开关旁的「序号设置」，分别设置「左侧导航」与「MD 正文与本文目录」的显示开关、起始层级、显示深度、层级或连续编号、数字格式、标点和淡色/加粗/徽标样式。正文可从 H1–H6 任一级标题开始，默认 H2 起显示三层；导航默认从「所有文档/仓库」分组的下一层开始编号，支持设置第 1–12 层为起点。「所有文档」旁的开关只控制左侧，正文开关只控制正文和右侧本文目录。两套开关默认均开，设置保存在当前浏览器、刷新后保留；「取消」不应用修改，「恢复默认」后点击「保存设置」才生效。复制正文、下载本页会保留当前编号，Markdown 源码和标题链接不变。
- 「查看源码」无需登录：弹出窗口直接显示当前文档的 Markdown 源码，可编辑、实时预览，并「保存到本地」（不会改动服务端文档）。
- 从搜索结果进入阅读模式时，命中工具条与按钮行会上下并排显示，互不遮挡；离开阅读模式后按钮行回到顶部。
- 右侧「本文目录」固定**贴着窗口右缘**；其左边缘是可用鼠标拖动的调节线，向左拖变宽、向右拖变窄（宽度记忆在本机，刷新后保持）。
- 搜索框放大镜右侧的 ⚙ 图标用于展开/收起「范围 / 模式 / 仓库」筛选（默认收起节省空间，筛选生效时图标高亮）。「仓库」是**多选**菜单：勾选一个或多个仓库后，搜索只在这些仓库里进行（可「全选/清空」，选择记忆在本机）；它与「范围」「模式」叠加生效。
- 导出的独立 HTML 中，本文目录固定在**左侧导航**，正文在右侧滚动。目录会**高亮当前阅读的章节**并自动展开其上级；右上角有「隐藏」按钮，隐藏后屏幕右缘会出现「目录」小标签，点击即可恢复。分级标题左侧的箭头可折叠/展开子章节。
- 绘图预览页提供「复制源码」按钮，可把左侧源码一键复制回文档；绘图示例中的每个图形都配有源码对照。
- AI 助手面板：上传文档入口在**输入框上方**（不在配置弹窗里）；「历史」可查看与切换本机保存的历史对话，「新对话」开始一份新记录。
- 设置入口：侧栏顶部 HOME 图标旁的单个「设置」图标（含 AI 配置）。窗口内可配置：**我的 AI 设置**（服务商/接口/模型/Key/代理策略/**参考源码路径**/资料范围，仅存本机浏览器）、**服务端设置**（管理员登录后配置 SVN 认证路径、仓库映射与全站 AI 默认值）、管理员改密。
- 反馈入口：侧栏「设置」图标旁的反馈图标，点击弹出反馈窗口（提交问题、粘贴截图、上传附件、查看进度）；配置页/总览页等没有侧栏的页面在右上角显示固定的「反馈」按钮。
- 文件夹视图右键菜单：在 `html/index_all.html` 的文件夹条目上右键可新建文档/新建文件夹/重命名/**移动到…**/删除（移入 `data/trash`，可找回）与设置分组（管理员）。左侧导航同样可以右键：分组标签带着真实目录，**空文件夹也会显示**，新建的子文件夹可直接右键在其中继续新建文档/子文件夹，不会落到别的目录里。
- 文档分组与移动：来自子文件夹的文档在列表里按文件夹分组，组标题显示文件夹路径与配置分组（子文件夹继承上级仓库的分组）。「移动到…」弹窗选择本仓库内的目标文件夹（跨仓库不允许）；移动会带上该文档引用的 `images/`、`附件/` 文件——只被本文档引用就移动，被同目录其他文档也引用则保留原件并在目标目录复制一份，目标目录已有同名且内容不同的资源会跳过并提示。
- 管理员登录：**本机管理员账号（默认 `admin / admin`）不需要 SVN 校验**，用页面右上角「登录」或设置窗口即可登录；侧栏会显示「管理员（本机）」。本机账号只能**本地编辑与保存草稿**；「提交 SVN…」时会提示输入一个 SVN 账号（仅本次合入使用，留在服务进程内存），因为仓库写入始终以真实 SVN 身份记录。
- 首页（`#/`）由构建生成，编辑器只提供只读预览并提示改从左侧目录打开 `docs/md` 下的文档；文档路由不带 `.md`（docsify 会去掉后缀）也能正常编辑与保存。
- 「参考源码路径」会随提问一起发给模型（如 `D:/repo/firmware` 或 `/srv/src/project`），便于 AI 回答时引用代码库位置。
