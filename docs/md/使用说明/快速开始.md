# 快速开始

欢迎使用 md2web。把 Markdown 放进 `docs/md/`，运行构建脚本即可生成完全离线的文档站。

## 阅读区工具栏

每篇文档右上角都有一排按钮：

- **复制路径**：复制该文档在仓库中的路径，便于在编辑器里打开
- **编辑 MD**：打开双栏编辑器——左侧 Markdown 源码按格式分色（标题层级、列表、代码块、公式），右侧实时预览（Mermaid、PacketDiag、KaTeX 公式、代码高亮）；`Ctrl+S` 直接写回 `docs/md/` 源文件（预览服务会自动重建），也支持另存为、下载、复制、还原与重新加载
- **下载 MD**：下载当前页面对应的 Markdown 源文件
- **下载本页**：把当前文档导出为自包含 HTML（含图片、图形与目录，可离线转发）
- **宽屏阅读** / **隐藏序号**：切换阅读布局与标题编号

编辑器常用快捷键：`Ctrl+B` 加粗 · `Ctrl+I` 斜体 · `Ctrl+K` 链接 · `Ctrl+M` 行内公式 · `Ctrl+Shift+M` 公式块 · `Ctrl+Alt+1/2/3` 标题 · `Ctrl+Shift+U`/`Ctrl+Shift+O` 无序/有序列表 · `Ctrl+Shift+K` 任务列表 · `Ctrl+Shift+C` 代码块 · `Ctrl+Shift+G` Mermaid · `Ctrl+Shift+D` PacketDiag · `Ctrl+S` 保存 · `Ctrl+/` 全部快捷键。

> 直连保存仅在 `python serve.py` 的本机预览下可用（局域网其他机器访问时接口拒绝写入）；`file://` 双击模式会改为「保存到文件」或下载。

左侧栏顶部还有「绘图预览」入口（<a href="lib/plot-playground.html" target="_blank" rel="noopener">lib/plot-playground.html</a>），可在线试写 Mermaid / PacketDiag 并下载图片。

## 数学公式

行内公式用 `$...$`，独立公式块用 `$$...$$`，由 KaTeX 离线渲染：

行内：$a^2 + b^2 = c^2$

$$
\int_{-\infty}^{+\infty} e^{-x^2}\,\mathrm{d}x = \sqrt{\pi}
$$

## 目录约定

- `docs/md/` 是唯一需要维护的目录，可自由创建子文件夹
- 图片无需登记，放在文档旁边或任意位置，用相对路径引用即可，例如 `![](images/flow.png)`
- 构建只处理 `.md` 文档；图片由浏览器直接加载

## 构建与预览

```
python setup_docsify.py
python serve.py
```

也可以直接双击 `docs/index.html` 浏览（file:// 模式，内容与搜索索引已内嵌）。

## Mermaid 图形

围栏语言写 `mermaid` 即渲染为图形（离线本地渲染）：

```mermaid
flowchart LR
  A[编写 Markdown] --> B[运行构建]
  B --> C[离线浏览与搜索]
```
