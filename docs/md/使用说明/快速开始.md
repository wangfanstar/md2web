# 快速开始

欢迎使用 md2web。把 Markdown 放进 `docs/md/`，运行构建脚本即可生成完全离线的文档站。

## 阅读区工具栏

每篇文档右上角都有一排按钮：

- **复制路径**：复制该文档在仓库中的路径，便于在编辑器里打开
- **编辑 MD**：打开双栏编辑器——左侧 Markdown 源码按格式分色（标题层级、列表、代码块、公式），右侧实时预览（Mermaid、PacketDiag、KaTeX 公式、代码高亮）；`Ctrl+S` 直接写回 `docs/md/` 源文件（预览服务会自动重建），也支持另存为、下载、复制、还原与重新加载
- **下载 MD**：下载当前页面对应的 Markdown 源文件
- **下载本页**：把当前文档导出为自包含 HTML（含图片、图形与目录，可离线转发）
- **宽屏阅读** / **隐藏序号**：切换阅读布局与标题编号

编辑器常用快捷键：`Ctrl+B` 加粗 · `Ctrl+I` 斜体 · `Ctrl+K` 链接 · `Ctrl+M` 行内公式 · `Ctrl+Shift+M` 公式块 · `Ctrl+Alt+1/2/3` 标题 · `Ctrl+Shift+U`/`Ctrl+Shift+O` 无序/有序列表 · `Ctrl+Shift+K` 任务列表 · `Ctrl+Shift+C` 代码块 · `Ctrl+Shift+G` Mermaid · `Ctrl+Shift+D` PacketDiag · `Ctrl+S` 保存 · `Ctrl+/` 全部快捷键。

> 直连保存仅在 `python serve.py` 的本机预览下可用（局域网其他机器访问时接口拒绝写入）；`file://` 双击模式会改为「保存到文件」或下载。

左侧栏顶部还有「绘图预览」入口（<a href="lib/plot-playground.html" target="_blank" rel="noopener">lib/plot-playground.html</a>），可在线试写 Mermaid / PacketDiag 并下载图片。

## AI 助手

右下角「AI 助手」按钮（或 `Ctrl+Shift+A`）打开对话面板：它会先在本地 `search-index.json` 中检索相关章节，再把资料片段与问题一起发给您配置的大模型，回答下方列出引用来源，点击即可跳转。

配置入口在**左侧栏顶部的 `AI 配置` 图标**（对话面板右上角「⚙ 配置」同样可打开），包含：

- **服务商与密钥**：OpenAI 兼容 / DeepSeek / Ollama 本机 / Anthropic / 自定义，填写接口地址、模型、API Key、温度、系统提示与请求方式，点「保存并测试」验证连通性
- **资料范围**：按文件夹/文档勾选，回答只依据所选资料（不勾选 = 使用全部文档）
- **上传文档**：可选择本机的 `.md` / `.markdown` / `.txt` 加入检索（单个 ≤ 256 KB、合计 ≤ 512 KB，仅保存在浏览器 localStorage，不会上传或提交到仓库）；上传文档会出现在资料范围的「upload://」分组中
- API Key 只保存在浏览器 localStorage，不会写入仓库或上传服务端；公开仓库请勿把 Key 提交进任何文件
- 请求方式默认「自动」：浏览器直连失败（通常是跨域）时自动改走本机 `serve.py` 的 `/__ai/chat` 代理（仅本机可调用）
- 完全离线（双击 `index.html`）时检索仍可用，但调用模型需要网络，且只能直连、不能走本机代理
- 快捷动作：「总结本页」「文档概览」「解释选中」（选中正文文字后点击）

## 目录约定

- `docs/md/` 是唯一需要维护的目录，可自由创建子文件夹
- 图片无需登记，放在文档旁边或任意位置，用相对路径引用即可，例如 `![](images/flow.png)`
- 构建只处理 `.md` 文档；图片由浏览器直接加载

## 构建与预览

```
python setup_docsify.py
python serve.py
```

也可以直接双击 `docs/index.html` 浏览（file:// 模式，内容与搜索索引已内嵌）：该模式为**离线只读**，保留搜索、图形、公式与下载能力。

## 登录与编辑权限

只读预览（`python serve.py`）不提供任何写接口。需要网页编辑时，用管理员准备的认证配置启动：

```
python -m pip install -r server/requirements.txt     # 仅服务机需要（Flask + Waitress）
python serve.py --config config/server.local.json     # 配置见 config/server.example.json
```

- 匿名读者仍可浏览、搜索、下载；右上角显示「登录」。
- 登录使用**自己的 SVN 账号密码**，服务端通过强制认证的 SVN 路径验证（不做匿名放行、不缓存口令、不写入数据库）。
- 会话默认 8 小时有效、闲置 30 分钟失效；服务重启或认证源变更后需重新登录。
- 写接口全部经过登录 + CSRF 校验，匿名请求一律拒绝；源文件写回使用版本校验，不再有"再次保存强制覆盖"。
- 各文档目录对应哪个 SVN 库由配置的 `repositories` 决定（最长目录匹配），页面会显示所属库与状态。

> 当前阶段已实现登录与只读边界（草稿保存与 SVN 提交在后续阶段启用，界面会给出明确提示）。工程师生成本地编辑与 SVN 提交的习惯不受影响，网站也不采集本地编辑过程。
