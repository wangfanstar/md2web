用户记录与排行榜

统计全部保留记录，按 IP 分类排行：同一 IP 的访问合并统计，未登录访客也计入排行；登录次数仅计算成功登录，文章总数为该 IP/账号阅读过的不同文章数。访问记录包含未登录访客、首页访问及文章阅读；每次打开或刷新文章计一次，文章总数不是作者贡献数量。历史未采集记录无法补算。时间按浏览器本地时区显示。

网站 SVN 备份

把网站数据（默认 docs/，含生成的页面、搜索索引与源文档）按频率定时合入到指定的 SVN 库； 凭据优先使用下面单独设置的备份账号（明文保存到当前 JSON），未设置时回退到「默认同步凭据」或环境变量同步凭据。

备份状态：（未启用或未检查） 「修复工作副本」执行 svn cleanup，修不好会自动移入 data/trash；「删除重建工作副本」会移入 data/trash 后立即重新检出并备份一次。

仓库回收站

恢复时一并还原仓库配置和本地资料。SVN 远端内容及软链接目标始终保留。

AI 默认配置

随当前 JSON 方案保存。SVN 账号验证使用上方「SVN 认证路径」，默认同步账号及各库专用账号也会写入当前方案。AI 默认值提供给已登录用户，个人 AI 设置可覆盖默认值。

上传大小

统一控制 PDF、Word、Excel、PPT、编辑器图片/附件和反馈附件的单文件大小，默认 500 MB（1 MB = 1024 × 1024 字节）。管理员修改后点击“保存全部修改”，立即生效并保存到当前 JSON 方案。多文件上传将自动分批。

缓存与性能

元数据缓存参数保存后需重启服务应用。版本检查周期将在后续支持配置；当前固定为 30 秒。

推荐初值与生效方式

有效期 60 秒、最多 256 项、容量 32 MiB。保存 JSON 不代表已重建内存缓存实例；请重启服务后使用新限制。

配置方案

默认内置三套可选配置：md2web_config.json（主配置）、md2web_config_default.json（默认配置）、md2web_config_backup.json（备份配置）；缺失时按当前配置自动生成快照，可在下拉中切换并分别保存。

修改后点击「保存配置并重建站点」，自动同步当前 JSON 并保留上一版。切换方案立即生效，重启继续读取默认方案；不会删除仓库文件。同步账号、密码及 AI Key 按明文保存在方案中，仅管理员接口可读；端口、数据库位置和服务密钥单独保留。

更新代码时请保留 docs/html/md2web_config*.json、config/server.local.json 和 data/。JSON 不受构建覆盖，并在 data/config-profiles/ 自动备份。
